# Prajwal Shetty Portfolio

A responsive single-page portfolio built with:

- HTML5
- Modern CSS3 (Grid + Flexbox)
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts (Inter)

## Files

- `index.html` — page structure/content
- `style.css` — theme, layout, responsive design and animations
- `script.js` — mobile menu, terminal typing, scroll reveal and mock contribution calendar

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Personalize

Search/replace these values in `index.html`:

- LinkedIn URL
- Email address
- Project GitHub URL
- Project descriptions
- GitHub statistics
- Education/current-learning text

The layout uses CSS Grid/Flexbox and flexible cards, so adding more text to most cards will make them grow rather than forcing fixed heights.
