01 CONTEXT
THE PROBLEM

What needed to work better?

The experience spans several areas and interactions: show bookings, shop actions, tutorials and demo dashboards. Demo data should remain available after a page refresh without a server.

THE SOLUTION

A focused product experience

String Master Puppetry brings those sections into one responsive client-side website, with browser localStorage retaining demo data between visits.
